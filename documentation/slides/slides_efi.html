🌐 A Grande Biblioteca Mágica

Imagine que a Internet é uma biblioteca onde os livros falam e os filmes saem das páginas.

💡 **Exemplo:** Quando você clica num vídeo de receita de bolo, o computador está "lendo" as instruções para você!

🤖 Como um robô toma banho?

Robôs precisam de instruções exatas!

  1. Entrar no box 🚿
  2. Abrir a torneira (não muito quente!)
  3. Passar sabonete 🧼
  4. Enxaguar e secar.

💡 Labirinto de Papel

**Passo a Passo:**

  1. Desenhe um labirinto simples no papel.
  2. Crie "cartas de comando" (⬅️ ➡️ ⬆️ ⬇️).
  3. Seu colega deve usar as cartas para guiar um bonequinho até a saída.

🎯 Isso é criar um **Algoritmo**!
