💡 Interruptores Gigantes

Os computadores não entendem letras. Eles entendem **Eletricidade**.

1 = LIGADO
0 = DESLIGADO

`01000001` = Letra "A" em binário!

🗺️ O Mapa da Decisão

Para programar, precisamos desenhar o caminho.

**INÍCIO** ➔ Está chovendo? ➔ **SIM** ➔ Pegar guarda-chuva 🌧️

➔ **NÃO** ➔ Passar protetor solar ☀️

Isso é uma estrutura de **Condição** (`if / else`).

🚀 Missão: Programação Humana

**Instruções:**

  1. Dividam-se em trios.
  2. Um aluno é o "Computador", outro é o "Programador" e o terceiro é o "Bug".
  3. O Programador cria comandos para o Computador atravessar a sala.
  4. O Bug pode interferir (dar um comando errado) uma vez!

💡 **Dica:** Trabalhem em colaboração para superar o bug!
